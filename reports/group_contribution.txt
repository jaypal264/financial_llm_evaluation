PILLAR 3: RETRIEVAL-AUGMENTED GENERATION (RAG) ARCHITECTURE
Primary Contributors: Jaypal Malviya, Anuj Kumar, Rup Narayan Jha (Equal Share)
--------------------------------------------------------------------------------

All three members developed and evaluated `src/rag_pipeline.py`, exploring the 
impact of dense vector search against gold-standard context:

• Jaypal Malviya (Lead on Document Chunking & Corpus Construction):
  - Formulated the document segmentation logic: 500-character chunks with 100-character 
    overlap stride across all three benchmark source texts.
  - Assembled the unified financial corpus comprising 3,101 clean passage chunks.
  - Guaranteed that reference answers and question annotations were strictly excluded 
    from the retrieval corpus to prevent data leakage.

• Anuj Kumar (Lead on Dense Vector Indexing):
  - Integrated `sentence-transformers/all-MiniLM-L6-v2` for 384-dimensional dense 
    semantic representations.
  - Implemented the exact L2 nearest-neighbor index using `faiss-cpu`.
  - Tuned batch embedding generation and similarity threshold filtering.

• Rup Narayan Jha (Lead on Context Assembly & RAG Diagnostics):
  - Implemented top-k context retrieval and prompt construction for Experiment B.
  - Diagnosed retrieval quality, identifying the root cause of the "RAG degradation" 
    effect: dense embeddings flatten tabular markdown, causing irrelevant adjacent 
    narrative chunks to dilute table figures.

• All Three Members Jointly:
  - Executed all 60 RAG-augmented live queries across the 4 models.
  - Conducted comparative error analysis contrasting Direct vs. RAG responses.

PILLAR 4: EVALUATION METRICS AND STATISTICAL ENGINE
Primary Contributors: Jaypal Malviya, Anuj Kumar, Rup Narayan Jha (Equal Share)
--------------------------------------------------------------------------------

All three members implemented `src/evaluation.py` and `calculate_metrics_and_plots.py`, 
covering seven distinct quantitative evaluation dimensions:

• Jaypal Malviya (Lead on Numerical Accuracy & Exact Match):
  - Implemented the numerical extraction and tolerance comparison engine:
    |pred - gold| / max(|gold|, 1e-6) <= 0.02 (2% relative error tolerance).
  - Built normalization filters for financial currency symbols ($, USD), commas, 
    and percentage notations (%).
  - Implemented string-normalized Exact Match (EM).

• Anuj Kumar (Lead on Lexical Faithfulness & Semantic Similarity):
  - Implemented the Lexical Faithfulness proxy metric measuring the fraction of 
    generated non-stopword tokens grounded in the provided context passage.
  - Integrated sentence-transformer embedding cosine similarity for semantic alignment.
  - Implemented abstention pattern detection for unanswerable queries.

• Rup Narayan Jha (Lead on Token F1, ROUGE-L & Efficiency Profiling):
  - Implemented SQuAD-style Token-level F1 (precision, recall, harmonic mean).
  - Integrated ROUGE-L longest common subsequence scoring.
  - Built latency measurement and token consumption trackers (prompt vs. completion).

• All Three Members Jointly:
  - Audited and cross-verified metric calculations on sample inputs against manual ground truth.
  - Built the consolidated metric export engine saving outputs to `results/metrics/` and 
    `results/summary/`.
